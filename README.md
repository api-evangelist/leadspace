Leadspace is a B2B GTM Data Intelligence Cloud and customer data platform. It unifies buyer data, account data, and buying signals into the Leadspace Universal Graph (v4) and exposes it as an enrichment API: submit a partial person or company record and receive a resolved entity with firmographics, corporate hierarchy, department sizes, funding and investor history, technology signals, weekly buyer intent, and persona and predictive fit scores.

- Website: https://www.leadspace.com/
- Developer guides: https://support.leadspace.com/hc/en-us/categories/5940743388306-Developer-Guides
- API base URL: https://apigw.leadspace.com
- Status: https://status.leadspace.com/

## APIs

| API | What it does |
|---|---|
| Leadspace Enrichment API v4 | Single (synchronous) and bulk (up to 500 records, async) person and company enrichment |
| Leadspace Discovery API | Account expansion — find net-new contacts inside up to 500 target accounts, ranked by persona |
| Leadspace Intent Only API | Weekly buyer-intent refresh returning surging topics and intent-model scores |

Leadspace publishes no machine-readable OpenAPI. The specs in `openapi/` were generated by API Evangelist from Leadspace's published technical specifications in the help center.

## Notes for integrators

- Auth is `Authorization: Bearer API_KEY` — either a perpetual token (rotate every 6 months, hard expiry at 2 years) or a 24-hour OAuth 2.0 token from `POST /oauth/authorize` with `audience: API_GATEWAY`.
- Single API is capped at 30 transactions per second per the customer's tiered SLA; breaches return 429.
- HTTP **427** is a non-standard Leadspace status for insufficient credits or an invalid program ID. It is terminal, not retriable.
- There is **no idempotency key**. `external_id` and `external_bulk_id` are correlation-only and explicitly not used for processing, so retries re-consume credits.
- Bulk jobs return 202 with a polling URI; 204 on the poll means still processing. An optional `callbackUrl` receives a completion POST.
- Errors use a proprietary envelope (`error`, `tracking_id`, `request_timestamp`, `details`), not RFC 9457.
- Leadspace is ISO 27001 certified and SOC 2 Type II audited; vulnerabilities go to https://www.leadspace.com/report-a-vulnerability (no bug bounty, safe harbor offered).
